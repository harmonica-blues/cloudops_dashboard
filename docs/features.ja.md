# CloudOps の機能

[プロジェクト紹介](../README.md) · **日本語** | [English](features.en.md)

各画面の用途と、表示される情報を紹介します。画面は日本語で、ライト・ダークの両テーマに対応しています。

このページに掲載するスクリーンショットには、個人情報や実環境の情報を含まない `screenshot` モードの架空データを使用します。起動方法は [README](../README.md#aws-なしで試す) を参照してください。

## 1. 概要

インフラ全体の状況をひとつの画面で確認します。

- **WAF のブロック数・許可数**: 選択した期間のリクエスト数と前期間からの増減を確認できます。
- **EC2 の CPU・メモリ**: インスタンスごとの平均使用率をリングで表示します。凡例はインスタンス名、使用率の順で表示します。
- **RDS の状況**: 接続数、CPU、空きストレージを確認できます。
- **調査へのショートカット**: 保存済みクエリをエディタに読み込めます。選択しただけでは実行しません。
- **EC2 一覧**: インスタンスごとの平均 CPU、平均メモリ、ステータスを比較できます。

## 2. WAF

リクエストの傾向と、ルールによる処理を調べます。

- **アクション別の集計・グラフ**: 許可、ブロック、カウント、チャレンジ、CAPTCHA の推移を表示します。
- **ルール別ブロック数**: 選択した期間のブロック数を上位 10 件まで表示します。
- **サンプルリクエスト**: 直近 3 時間の時刻、アクション、IP、国、メソッド、URI、ルールを確認できます。IP・URI・ルールで絞り込めます。
- **アクションの色分け**: サンプル一覧では ALLOW は緑、BLOCK は赤、COUNT は青、CHALLENGE / CAPTCHA は黄で表示します。日本語のラベルにも対応します。

サンプルはすべての通信を記録したものではありません。また、期間セレクターにかかわらず直近 3 時間を表示します。全件ログを調査する場合は Athena を使用します。この画面の取得には Athena を使いません。

## 3. EC2

インスタンスの状態と、リソース使用率を確認します。

- **集計カード**: インスタンス数、正常なインスタンス数、平均 CPU、平均メモリを表示します。
- **時系列グラフ**: インスタンス間の CPU・メモリの傾向を比較できます。
- **詳細一覧**: インスタンス名・ID、CPU とメモリの平均値・最大値、稼働状態、アベイラビリティーゾーンを表示します。
- **検索**: インスタンスを絞り込めます。

メモリ使用率には CloudWatch Agent などによるメトリクス送信が必要です。AWS モードで取得できない値は `データなし` と表示します。

## 4. RDS

データベースの負荷と容量の変化を確認します。

- **CPU 使用率**: 平均値、最大値、時系列を表示します。
- **接続数**: 接続数の平均・最大と推移を確認できます。
- **書き込みレイテンシ**: ミリ秒単位で平均・最大と推移を表示します。
- **空きストレージ**: 最新の空き容量と時系列を表示します。
- **インスタンス詳細**: 識別子、エンジン、ステータスを確認できます。

## 5. Athena クエリ

WAF ログを SQL で調査します。AWS モードでは Athena・Glue・S3 の設定と権限が必要です。

- **保存済みクエリ**: IP 別、国別、ルール別などの SQL テンプレートを選び、実行前に編集できます。
- **SQL エディタ**: 読み取り用の `SELECT` / `WITH` を受け付けます。`log_time` の範囲指定が必要です。
- **使用額の表示**: 今日の推定使用額と上限を確認できます。上限到達時は実行を停止します。
- **実行履歴**: 実行者、状態、所要時間、スキャン量、推定コストを表示します。実行中のクエリはキャンセルできます。
- **結果表示**: 最大 1,000 行まで画面に表示し、全件は CSV で取得できます。
- **共有制御**: 「結果を共有しない」を選ぶと、SQL・結果・エラー・CSV は実行者だけが閲覧できます。実行者や状態などの履歴は他のユーザーにも表示されます。

実行できるクエリは同時に 1 件までです。`screenshot` モードの結果と使用額は架空で、SQL 実行と CSV ダウンロードは無効です。

## 6. 共通機能

| 機能 | 内容 |
| --- | --- |
| 期間選択 | 過去 1 日・7 日・30 日、または最大 90 日のカスタム期間 |
| 前期間との比較 | 直前の同じ長さの期間に対する増減を表示 |
| テーマ | ライト・ダークを切り替え、選択をブラウザに保存 |
| 自動更新 | 60 秒ごとにキャッシュを再読込。カスタム期間や非表示のタブは対象外 |
| 手動更新 | 更新ボタンで選択期間のデータを再取得 |
| ログイン | ユーザーごとのセッションと、自分のパスワードの変更 |
| 操作ログ | ログイン・クエリ実行などを SQLite に記録 |
| 収集の一時停止 | アクセスがないときは定期収集を停止し、次のアクセスで再開 |

日時の集計は UTC、表示は設定したタイムゾーンです。カスタム期間は JST で入力します。ユーザー管理と利用額による停止の解除はコンテナ内の CLI で行います。
